Alten Spielstand sichern

Exportiere den klassischen Spielstand aus diesem Browser. Dabei werden keine gespeicherten Daten verändert. Kampagne und POV-Meisterschaft haben eigene Speicherbereiche.

Archivierte Version verwenden

Der geprüfte Stand ist unter classic-simulation-archive-2026-11-21 gesichert.

  1. Den verlinkten Git-Stand auschecken oder als ZIP herunterladen.
  2. Im entpackten Ordner mit Node.js 24 npm ci und npm run build:offline ausführen.
  3. Die erzeugte dist/carpet-grand-prix-offline.html öffnen und deinen JSON-Spielstand importieren.

Alternativ kann die archivierte Website lokal bereitgestellt und über index.html?legacy=1 geöffnet werden. Ein anderer Browser, Port oder Dateipfad kann einen eigenen Speicherbereich besitzen; deshalb zuerst exportieren.
