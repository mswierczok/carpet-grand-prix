# Eigene Fahrerporträts

Hier die Originalporträts als PNG hochladen:

- Dateinamen: `d001.png` bis `d035.png`
- Jede Nummer gehört zur gleichnamigen festen Fahrer-ID.
- Die Kürzel müssen nicht im Dateinamen stehen.
- Dateien direkt in diesen Ordner laden, ohne einen weiteren Unterordner.

Die Bilder werden anschließend in das Porträtsystem eingebunden. Der Upload allein ersetzt noch keine Spielgrafiken. Die vorhandenen SVG-Porträts im übergeordneten Ordner bleiben erhalten.
