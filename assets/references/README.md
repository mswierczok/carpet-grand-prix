# Referenzbilder für Carpet Grand Prix

Hier werden Fotos der ursprünglichen Spielzeug-Rennwagen gesammelt. Sie dienen als Designvorlagen für die fiktiven Lackierungen der 13 Teams; echte Marken und Sponsoren sollen **nicht** auf die finalen Spielgrafiken übernommen werden.
